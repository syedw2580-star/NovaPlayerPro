1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Nova Player Pro is a high-fidelity, client-side web media player engineered for
modern desktop and mobile web browsers. Built as a self-contained web application,
it overcomes the long-standing limitations of standard HTML5 video elements:
  • Multi-channel 5.1 surround sound matrix downmixing (resolving silent/muted dialogue).
  • 300% Smart Audio Booster with a 2-stage dynamic compression and soft-clipping limiter.
  • Dedicated Center-Channel Dialogue Boost (+6dB, +12dB) for vocal clarity.
  • In-browser MKV (EBML) & MP4 (ISO BMFF) embedded audio & subtitle track demuxing.
  • Dynamic Expand / Compact sidebar dock (440px ↔ 660px) for flexible viewing.
  • Live HLS (.m3u8) adaptive bitrate streaming with auto-reconnecting buffer recovery.
  • 3D Stereoscopic display engine (Side-by-Side and Top-and-Bottom hardware transforms).
  • High-performance Yellow Subtitles engine with millisecond timing sync.
  • Offline media library and bookmark persistence using native browser IndexedDB.

3. WEB AUDIO DSP ENGINE (AudioEngine)
--------------------------------------------------------------------------------
The AudioEngine manages the Web Audio API lifecycle to ensure pristine audio reproduction:

A. 6-Channel 5.1 Surround Sound Matrix Downmixer:
   Standard HTML5 video elements often drop or suppress Channel 2 (Center/Dialogue)
   when playing 5.1 AAC/AC3 audio on 2-channel stereo headphones or laptop speakers.
   Nova Player Pro uses an explicit 6-channel ChannelSplitterNode(6):
     - Channel 0: Left Front
     - Channel 1: Right Front
     - Channel 2: Center (Dialogue) — matrix-mixed into L & R at 0.707 gain (-3dB).
     - Channel 3: Subwoofer (LFE) — mixed into L & R at 0.5 gain.
     - Channel 4: Left Surround — mixed into L at 0.707 gain.
     - Channel 5: Right Surround — mixed into R at 0.707 gain.
   Recombined into a 2-channel ChannelMergerNode(2) with explicit channelCount = 2.

B. Smart Audio Booster & Soft-Clipping Limiter (300% Safe Loudness):
   A 2-stage dynamic compression and soft-clipping limiter chain:
     1. DynamicsCompressorNode:
        - Threshold: -24 dB | Knee: 30 dB | Ratio: 12:1
        - Attack: 0.003s | Release: 0.25s
        Pulls down harsh spikes while lifting faint whispers and dialogue.
     2. WaveShaperNode Limiter:
        Hyperbolic tangent (Math.tanh(x * 1.5)) transfer curve across 44,100 samples.
        Clamps maximum output at 0 dBFS (+1.0 amplitude) to eliminate digital clipping
        and speaker distortion even at 300% volume.

C. Center-Channel Dialogue Boost (+6dB / +12dB):
   Enhances dialogue frequency formants and center gain for clear speech during
   heavy background music or action sequences.

D. 5-Band Equalizer:
   Hardware biquad filter presets: Flat, Bass Boost, Vocal, Cinema, and Treble.

4. EMBEDDED STREAM DEMUXING & MULTI-TRACK SWITCHING
--------------------------------------------------------------------------------
Nova Player Pro reads and extracts tracks directly inside the client browser:
  • Matroska (MKV) Demuxer:
    - Parses EBML Header, Segment Information, Tracks Element (0x1654AE6B), and Clusters.
    - Extracts TrackType 1 (Video), 2 (Audio), and 17 (Subtitles: UTF8, ASS/SSA).
    - Decodes SimpleBlock and BlockGroup timecodes with cooperative async yielding.
  • MP4 (ISO Base Media File Format) Demuxer:
    - Walks the box tree: ftyp -> moov -> trak -> mdia -> minf -> stbl.
    - Identifies audio (soun) and subtitle/text handlers (sbtl, subt, text, tx3g).
    - Decodes sample description tables (stsd) and chunk offset tables (stco/co64).
  • On-Demand Extraction:
    - Only demuxes the active subtitle track when selected to preserve CPU and memory.
    - Uses AbortController to cancel previous background tasks if the user switches tracks.
